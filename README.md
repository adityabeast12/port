# Aditya Shukla — Portfolio

A portfolio you can chat with. Visitors pick a suggested question or type their own, and get a streamed answer with rich content: project cards, an example agent trace, the tech stack, the experience timeline and contact buttons. A WebGL particle orb sits behind the chat. It speeds up while "thinking" and changes shape with the topic.

The answers are written ahead of time rather than generated by a live model, so the site needs no API keys or server and runs on GitHub Pages.

It is a static site with no build step. Serve it with any static server, for example:

```sh
python3 -m http.server 8000
```

## Structure

- `index.html`: page shell (header, welcome screen, chat log, composer)
- `assets/js/kb.js`: **all answer content**. Edit this to change what the chat says.
- `assets/js/main.js`: question routing, answer streaming, rich blocks, orb control
- `assets/js/scene.js`: the WebGL particle field (three.js). It has five shapes: core, agent network, waveform, guarded core and galaxy.
- `assets/css/style.css`: styles
- `assets/vendor/three.module.min.js`: bundled three.js 0.169

## Editing answers

Each topic in `kb.js` has:

- `q`: the chip label
- `keys`: words that route a typed question to it. Longer matches win, and keys of three characters or fewer must match whole words.
- `shape`: the orb shape for that topic
- `text`: paragraphs, with `**bold**` supported
- `blocks`: rich content
- `next`: follow-up chips

Typed questions that match no topic get a fallback answer that points to email.

You can link straight to a topic with a hash, for example `…/port/#banking`.

The site respects `prefers-reduced-motion`. If WebGL is unavailable it falls back to a plain gradient.
