Approach

    Decompose

    Break the problem into requirements, data flows and service boundaries. I own the requirement breakdown and the sprint board, and delegate to developers.

  2. 02

    Prototype

    Build a working POC quickly, with a Streamlit or React front end on FastAPI, using AI-assisted development to iterate faster.

  3. 03

    Connect agents, tools, retrieval and document pipelines into one system, using CrewAI, LangChain, AutoGen, LlamaParse and Docling.

  4. 04

    Govern

    Add guardrails, tracing and model monitoring from day one, so every flow can be inspected, debugged and audited.

Responsible AI

Guardrails come first, not last

In banking, an agent that is right 95% of the time is not good enough. Every system I build is designed to be safe, visible and auditable.

Guardrails

Policy checks on every input and output, scope limits and PII handling, so an agent knows what it must never do.

Observability

Every agent step is traced in Langfuse, including latency, tokens, tool calls and failures.

Governance

Governance is part of the design. Models are monitored after launch, with a clear trail from each decision back to its data.

Security

VAPT testing with Burp Suite, because an assistant that can move money has to hold up against attackers.
